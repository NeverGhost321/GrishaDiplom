# PROJECT SUMMARY

## Назначение приложения
Приложение автоматизирует подбор игровых ПК-конфигураций и помогает собирать совместимые наборы комплектующих в рамках заданного бюджета.

## Какие задачи ВКР закрывает
- Снижение количества ошибок при подборе аппаратных компонентов.
- Формализация проверок совместимости в виде программных правил.
- Предоставление пользователю понятного интерфейса для выбора и анализа сборки.

## Какие проблемы совместимости учитываются
- несовпадение сокета CPU и материнской платы;
- несовместимость по типу/частоте RAM;
- недостаточная мощность БП для выбранной видеокарты и системы;
- ограничения корпуса по длине видеокарты и высоте кулера;
- ограничения по интерфейсам и линиям PCIe для накопителей.

## Какие компоненты входят в модель данных
- CPU;
- Motherboard;
- RAM;
- GPU;
- PSU;
- Storage;
- PcCase;
- Cooler;
- SavedBuild (сохранённая пользовательская сборка).

## Какие проверки реализованы
- проверка связки CPU + motherboard;
- проверка RAM на уровне платформы;
- проверка питания и рекомендованной мощности БП;
- проверка физической совместимости компонентов с корпусом;
- проверка хранения данных (SATA/M.2/NVMe);
- расчёт итоговых метрик совместимости и энергопотребления.

## Какие результаты можно получить
- автоматически сгенерированную совместимую сборку;
- ручную сборку с валидацией;
- отчёт по совместимости (ошибки/предупреждения/рекомендации);
- сохранённые конфигурации для повторного просмотра;
- экспорт результатов в JSON и PDF.
