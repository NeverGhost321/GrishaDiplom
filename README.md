# Конфигуратор игровых ПК

## Краткое описание
Веб-приложение предназначено для подбора совместимых игровых конфигураций персональных компьютеров в заданном бюджете.

## Цель проекта в контексте ВКР
Разработка программного инструмента для минимизации ошибок аппаратной совместимости при подборе комплектующих игрового ПК.

## Основные возможности
- автоматический подбор сборки;
- ручная сборка;
- проверка совместимости;
- расчёт энергопотребления;
- сохранение конфигураций;
- просмотр сохранённых сборок;
- экспорт JSON/PDF;
- каталог компонентов.

## Технологический стек

## Структура проекта
- `app/` — страницы и API-роуты Next.js (App Router);
- `src/services/` — бизнес-логика совместимости и автогенерации;

- `src/types/` — типы доменной модели;
- `prisma/` — схема БД, миграции, seed;
- `tests/e2e/` — e2e-тесты Playwright.

## Основные пользовательские сценарии
1. Пользователь открывает каталог и изучает доступные комплектующие.
2. Пользователь выбирает автоподбор, вводит бюджет и получает совместимую сборку.
3. Пользователь может собрать конфигурацию вручную, проверив совместимость.
4. Сборка сохраняется в БД и доступна в разделе сохранённых сборок.
5. Для сохранённой сборки доступны детальный просмотр и экспорт в JSON/PDF.

## Демонстрационный сценарий
1. Открыть главную страницу.
2. Перейти в каталог компонентов.
3. Показать доступные компоненты.
4. Перейти в автоматическую сборку.
5. Ввести бюджет.
6. Сгенерировать совместимую конфигурацию.
7. Показать статус совместимости.
8. Сохранить сборку.
9. Открыть сохранённые сборки.
10. Перейти в детальный просмотр.
11. Показать список комплектующих, энергопотребление, предупреждения.
12. Экспортировать сборку в PDF.

## API endpoints
### Каталог комплектующих
- `GET /api/components/cpus`
- `GET /api/components/motherboards`
- `GET /api/components/rams`
- `GET /api/components/gpus`
- `GET /api/components/psus`
- `GET /api/components/storages`
- `GET /api/components/cases`
- `GET /api/components/coolers`

Поддерживаются query-параметры: `search`, `manufacturer`, `minPrice`, `maxPrice`, `sort`.

### Сборки
- `POST /api/builds/generate` — автогенерация сборки;
- `GET /api/builds` — список сохранённых сборок;
- `POST /api/builds` — сохранение сборки;
- `GET /api/builds/[id]` — детальная информация;
- `DELETE /api/builds/[id]` — удаление сборки;
- `GET /api/builds/[id]/export` — экспорт JSON;
- `GET /api/builds/[id]/export/pdf` — экспорт PDF.

### Совместимость
- `POST /api/compatibility/check` — проверка совместимости выбранных компонентов.

## Логика проверки совместимости
Проверки покрывают:
- CPU ↔ motherboard (сокет, поколение, ограничения платформы);
- motherboard ↔ RAM и CPU ↔ RAM (тип памяти, частоты, объём);
- GPU ↔ PSU (рекомендованная мощность, запас питания, 12VHPWR);
- габариты GPU/кулера/форм-фактора материнской платы ↔ корпус;
- накопители ↔ motherboard (SATA/M.2/NVMe, PCIe-ограничения);
- расчёт метрик: энергопотребление, рекомендуемая мощность БП, итоговая стоимость и оценка совместимости.

## Ограничения текущей версии
- Используются демонстрационные seed-данные, а не динамические рыночные цены.
- Ряд проверок базируется на эвристиках и не заменяет официальные спецификации производителей.
- Нет авторизации пользователей и персональных кабинетов.

## Возможные направления развития
- интеграция с внешними источниками цен и наличия;
- расширение совместимости по редким аппаратным сценариям;
- пользовательские профили и история сборок;
- более гибкий конфигуратор приоритетов автоподбора;
- экспорт в дополнительные форматы и сравнение нескольких сборок.
