# Конфигуратор игровых ПК (ВКР)

Базовый full-stack проект на **Next.js + TypeScript + Tailwind CSS + Prisma + SQLite** для разработки веб-приложения-конфигуратора игровых ПК.

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env` по примеру:

```bash
cp .env.example .env
```

3. Сгенерируйте Prisma Client:

```bash
npm run prisma:generate
```

4. Примените миграции:

```bash
npm run prisma:migrate -- --name init
```

5. (Опционально) Заполните базу тестовыми данными:

```bash
npm run prisma:seed
```

6. Запустите приложение:

```bash
npm run dev
```

Приложение будет доступно на `http://localhost:3000`.

## Скрипты

- `npm run dev` — запуск в режиме разработки.
- `npm run build` — production-сборка.
- `npm run lint` — проверка ESLint.
- `npm run prisma:generate` — генерация Prisma Client.
- `npm run prisma:migrate` — запуск Prisma миграций.
- `npm run prisma:seed` — заполнение БД начальными данными.

## Структура базы данных

В проекте используется **SQLite** через Prisma. Временная таблица `Component` заменена на полноценную схему для конфигуратора игровых ПК.

### Основные таблицы комплектующих

- `Cpu` — процессоры (производитель, сокет, поколение, ядра/потоки, частоты памяти, TDP, score, цена).
- `Motherboard` — материнские платы (сокет, чипсет, поддержка поколений CPU, RAM/PCIe/M.2/SATA характеристики, цена).
- `Ram` — оперативная память (тип, объем модуля и комплекта, частота, тайминги, цена).
- `Gpu` — видеокарты (производитель GPU и платы, VRAM, энергопотребление, PCIe, score, цена).
- `Psu` — блоки питания (мощность, сертификат, коннекторы, 12VHPWR, надежность, цена).
- `Storage` — накопители (интерфейс, PCIe-версия для NVMe при необходимости, объем, скорость чтения, форм-фактор, цена).
- `PcCase` — корпуса (поддерживаемые форм-факторы плат, ограничения по длине GPU и высоте кулера, отсеки накопителей, цена).
- `Cooler` — кулеры (совместимые сокеты, TDP, высота, тип, цена).

### Сборки

- `Build` — пользовательская сборка ПК.
- Каждая запись `Build` хранит ссылки на выбранные комплектующие (`cpuId`, `motherboardId`, `ramId`, `gpuId`, `psuId`, `storageId`, `caseId`, `coolerId`) и поля `budget`, `totalPrice`, `createdAt`.
- Для полей, где могут храниться массивы значений (например, список сокетов или форм-факторов), используются строки (`String`) в формате CSV или JSON-строки.
