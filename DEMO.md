# DEMO: сценарий защиты ВКР

## Что показать
- Работу конфигуратора игровых ПК в двух режимах: автоматическом и ручном.
- Проверку совместимости и расчёт энергопотребления.
- Сохранение сборки и экспорт в JSON/PDF.

## Предварительные команды
```bash
npm install
npx prisma generate
npx prisma migrate dev
npm run prisma:seed
npm run dev
```

## Последовательность демонстрации
1. Открыть `/` и кратко объяснить цель проекта.
2. Перейти на `/components` и показать категории и фильтры.
3. Перейти на `/auto-build`, ввести бюджет, выполнить генерацию.
4. Показать результат совместимости, итоговую цену и энергопотребление.
5. Сохранить сборку.
6. Открыть `/saved-builds`, найти сохранённую запись.
7. Перейти на `/builds/[id]` и показать состав комплектующих, предупреждения, метрики.
8. Выполнить экспорт JSON и PDF.
9. Дополнительно открыть `/manual-build` и показать сценарий ручного выбора компонентов.

## На что обратить внимание комиссии
- Проверка аппаратной совместимости снижает риск ошибочного подбора.
- Автогенерация учитывает бюджет и даёт готовую конфигурацию.
- Есть прозрачные метрики: цена, мощность БП, энергопотребление, предупреждения.
- Реализованы сохранение и воспроизводимость результата (детальная страница + экспорт).
